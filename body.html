Diacritics — all marks
How editing works Every node carries its own radius, so thickness varies along a stroke. Click a node to select it — drag to move, drag its marching ring to swell or pinch, or type exact X / Y / R above. Add nodes for finer detail on tight curves. Vietnamese letters are built from a base letter plus shared marks: select one and the grey mark nodes edit that mark everywhere it is used. MELT controls how much neighbouring blobs fuse.
